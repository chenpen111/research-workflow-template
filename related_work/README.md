# Related Work

检索的目标是形成精确、可追溯的候选集；研究问题未明确前不批量下载。

## 单篇结构

```text
related_work/<论文短名>/
├── paper.pdf
└── source/       # arXiv LaTeX 源码
```

通读 PDF；核对公式、表格和引用时查 LaTeX 源码。若来源不提供可用源码，在论文目录记录原因。

## 检索与归档

1. 根据研究问题设计检索式，记录数据库、时间、筛选标准、保留与排除理由。
2. 先检查当前主机是否已安装并可使用 `deepxiv-cli`，按其 skill 指引检索、初筛和分层阅读；不要引用其他主机的 CLI 路径。
3. 人工核对论文题目、标识符和相关性；确定收藏的 arXiv 论文后，按 `research-workflow` 指引将 PDF 和 LaTeX 源码保存在同一论文目录。
4. 验证 PDF 可打开、源码中确有 `.tex`；工具或源码不可用时记录真实状态。
